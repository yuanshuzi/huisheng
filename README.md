# 回声 Echo · 聊天回放器

把一段纯文本剧本变成可以录屏的聊天对话。节奏由字数自动计算，消息通过 `async / await` 串行播放，气泡、输入状态和界面切换全部由 CSS 动效渲染。支持双人对话与多人群聊故事，人物数量、名字、状态、头像都可以在控制台里改。

## 运行

直接双击 `index.html` 即可。

也可以启动本地静态服务：

```bash
node server.js
# 打开 http://127.0.0.1:4173
```

## 功能

- **人物 / 初始对话 / 剧本配置**：集中在 `app.js` 顶部的 `CONTACT`、`INITIAL`、`SCRIPT`。
- **群聊故事模式**：控制台“人物”里可在“双人对话 / 群聊故事”之间切换。群聊最多 12 位人物（含自己），可点“添加人物”新增、点行尾减号移除，也能改群名。顶栏会换成群名 + “N 人 · 在线”和叠放头像，对方气泡上方显示人物名字。
- **自己也可以显示头像**：双人对话时可勾选“显示我的头像”；群聊里强制开启，自己的消息右侧会带上头像。
- **纯文本剧本**：支持人物台词、系统提示、时间分割线和注释。
- **按字数算节奏**：`calcTiming()` 根据台词字数计算等待时间和“正在输入”时长。
- **串行播放**：`playScript()` 使用 `async / await` 逐条播放，可暂停、继续、重播、调速。
- **播放前倒计时**：播放、重播、应用剧本、导入和重置都会先倒数（默认 6 秒，可在播放器右侧调成 0–30 秒），方便先按下录屏再开演。倒计时数字显示在手机画面中央，期间点播放键或按 `Esc` 可取消；设为 0 秒即立即播放。秒数会记住。
- **DOM 渲染器**：`buildNode()` 负责把 `message` / `system` / `time` 三种节点转换成 DOM。
- **手动输入**：直接在手机输入框发消息；`Enter` 发送，`Shift + Enter` 换行，支持中文输入法组合态。
- **自定义头像**：点击顶栏头像，或控制台“人物”里的任意头像，上传 JPG / PNG / WebP；图片会自动裁成 256×256 方形 WebP 并保存在本地。顶栏、消息气泡、输入状态和人物编辑区会同步更新，右上角小按钮可恢复默认文字头像。
- **导入剧本**：顶部“导入剧本”按钮打开弹窗，粘贴文本后实时解析预览，确认后替换剧本并自动播放。剧本里出现不认识的人名时会自动创建人物（预览会提示“将创建：…”），人物超过两位会自动切到群聊。弹窗内提供“填入群聊示例（3 人）”。
- **文本转对话**：「01 剧本」右上角点“文本转对话”，把一段叙述粘进去，按句号自动切成一个个气泡；可逐句指定人物，也可勾选多句批量修改。单独一行的时间会被识别成时间节点，并能在列表里直接改。没指定人物时默认沿用上一位人物。
- **录屏模式**：隐藏工作台与面板，只保留手机画面；鼠标静止后控制条也会淡出，按 `Esc` 退出。
- **可收起顶栏**：点击顶栏最右侧的收起按钮，或按 `H`，把工具栏收起以扩大画面；收起状态会记住，右上角浮动按钮可随时展开。
- **两套主题**：白日（单列对话流、白色对方气泡、蓝白渐变自己气泡）与夜晚，可在顶栏切换并记住选择。夜晚以 `#0F1720 → #162230` 的柔和渐变打底，主文字 `#E6EDF5`、辅助文字 `#9FB0C3`，阴影统一用 `rgba(0,0,0,0.28)`；`#6FA8FF` 只出现在发送按钮和焦点态（输入框聚焦、勾选框、倒计时圆环），没有纯黑背景、荧光蓝或霓虹紫。两种主题下手机外壳都是近黑金属边框。
- **移动端适配**：控制台变成侧滑抽屉，手机预览自适应屏幕。
- **作者主页**：控制台「04 关注」里有抖音、小红书、B站入口，均在新窗口打开。

## 剧本语法

```text
# 以 # 或 // 开头的是注释，不会播放
[时间] 今天 21:07
[系统] 你们已互相关注

林雾：你那边，雨停了吗？
沈言：刚停。窗户上全是水。
林雾：那正好，适合讲一个很长的故事。
```

支持：

| 语法 | 作用 |
| --- | --- |
| `林雾：台词` | 左侧对方消息 |
| `沈言：台词` | 右侧自己消息 |
| `我：台词` / `对方：台词` | 使用别名指定左右 |
| `[系统] 内容` / `系统：内容` | 灰色系统提示 |
| `[时间] 21:07` / `[21:07]` | 时间分割线，同时更新手机状态栏时间 |
| `# 注释` / `// 注释` | 跳过该行 |

说话人通过 `CONTACT` 里的 `name`、对象 key 或 `aliases` 匹配。修改昵称后，旧昵称会自动保留为别名，已有剧本不会失效。

### 群聊剧本

安排三个人以上时，直接让每个角色说话即可，第一行出现的陌生名字会变成新人物：

```text
[时间] 今天 23:40
[系统] 你邀请「江栖」加入了群聊
林雾：都睡了吗？
沈言：没。在等一个人先开口。
江栖：刚洗完澡，发生什么了？
林雾：沈言说，他有件事一直没告诉我们。
```

- 除自己之外有两位以上人物时，自动进入群聊渲染：左侧每条消息带头像与说话人名字，右侧自己的消息也带头像。
- 连续同一人发言时只显示第一行的名字，避免重复。
- 群聊里人物的头像底色会按顺序自动分配，改名字时文字头像的首字也会跟着更新。

## 文本转对话

控制台「01 剧本」右上角的「文本转对话」，可以把一段叙述直接拆成对话气泡，不用手写「人物：台词」。

1. 把整段文字粘到左边，以 `。` 为气泡终点（`！？…` 也会断句），右栏会逐句列出来。
2. 每一句都能选由谁说。没动过的句子默认沿用上一句的人，第一句默认给对方；改一句会顺着影响后面还没手动指定的句子。
3. 勾选左侧小方框可以多选，再用批量栏的人物下拉 + 「批量设定」把选中的句子一次改成同一个人；「全选」旁的计数会实时显示已选数量。批量修改只作用于勾选的消息，不会顺着影响后面的句子。
4. 「插入到剧本」把结果追加到现有剧本末尾，「替换并回放」用结果替换剧本并立即播放。
5. 右上角的「全部」下拉可以一次性把整段都指定给同一个人。

### 时间识别

单独一行的时间会变成时间节点，并在右侧列表里显示成可编辑输入框；改完直接写回剧本的 `[时间] …`：

```text
23:40
今天 23:40
昨晚 23:58
2024-05-01 23:40
5月1日 晚上八点
昨天晚上八点半
凌晨三点
[时间] 昨晚十点
时间：08:15
```

- 带句号、问号等句子标点的行不会被当成时间，所以「他说：23:40。」仍是台词。
- 时间节点不参与人物分配，也不会打断“沿用上一句人物”的规则。
- 改时间后继续改左边的正文（哪怕改错别字）不会丢掉手动改过的时间；整段换成新文字才会重新识别。

几句补充：

- 句首写 `林雾：` 时，只有「林雾」已经在人物表里才会被认成说话人，名字会从气泡里去掉。
- 不在人物表里的人名不会被自动创建：整句会原样保留文字，说话人沿用上一位。想让他真的说话，先去「02 人物」加人，再回来重新粘一次。
- 改错别字时已经选好的人物和勾选状态不会丢；整段换成新文字则会重新按默认规则分配。


## 代码结构

```text
index.html   页面结构、图标、手机外壳、控制台、导入弹窗
styles.css   工作台视觉、手机 UI、气泡动效、响应式、录屏模式
app.js       配置 + 解析器 + 时间计算 + 渲染器 + 播放引擎 + 交互
server.js    可选的本地静态服务器
```

核心函数：

```js
parseScript(text)       // 纯文本 → [{ type: 'message' | 'system' | 'time', ... }]
calcTiming(item, opts)  // 返回 { chars, wait, typing, after, total }
buildNode(item)         // 数据对象 → HTMLElement
playScript(nodes, opts) // async/await 逐条播放，支持暂停与倍速
splitBlocks(text)       // 一段叙述 → [{ type: 'message' | 'time', text }]
matchTimeLine(line)     // 单独一行的时间 → 时间文本，否则 null
```

人物相关：

```js
renderContactEditor()   // 重绘控制台人物列表
setChatMode('group')    // 切换双人 / 群聊（群聊会自动补到 3 人）
addContact()            // 新增一位人物
removeContact(id)       // 移除人物（自己不可移除，至少保留一位对方）
setShowSelfAvatar(true) // 自己的消息是否显示头像
```

时间公式（可在 `TIMING` 中调整）：

- 消息等待：`waitBase + 字数 × waitPerChar`，再限制在 `waitMin ~ waitMax`。
- 对方输入：`typingBase + 字数 × typingPerChar`，同样有上下限；播放时显示跳动的“正在输入”气泡。
- 每条消息另有 `after` 留白，保证气泡不会挤在一起。
- `pace` 调整整体节奏，播放器倍速会实时作用于正在等待的那一步。

打开浏览器控制台可以使用：

```js
ChatReplay.parseScript('林雾：你好')
ChatReplay.calcTiming({ type: 'message', from: 'other', text: '你好呀' })
ChatReplay.playScript(ChatReplay.state.script, { from: 0 })
ChatReplay.setSpeed(1.5)
ChatReplay.setChatMode('group')
ChatReplay.splitSentences('雨停了。她把窗推开。')
ChatReplay.splitBlocks('23:40\n雨停了。她把窗推开。')
ChatReplay.matchTimeLine('今天 23:40')
ChatReplay.setCountdown(6)      // 0 表示不倒计时
ChatReplay.requestPlayback()    // 带倒计时的播放入口
ChatReplay.GROUP_SAMPLE
```

## 本地保存

顶栏收起状态、主题、人物阵容和自定义头像保存在浏览器 `localStorage`，刷新页面后仍然保留：

- `echo-theme`：`day` / `night`
- `echo-topbar-collapsed`：`1` / `0`
- `echo-countdown`：播放前倒计时秒数（`0`–`30`）
- `echo-avatars-v1`：各个人物的方形 WebP 头像数据
- `echo-cast-v1`：人物名单、群名、对话模式、是否显示自己的头像

清除站点数据即可恢复默认人物、默认头像和默认布局。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| `Enter` | 发送输入框内容 |
| `Shift + Enter` | 输入框内换行 |
| `Space` | 播放 / 暂停 |
| `R` | 从头重播 |
| `F` | 进入 / 退出录屏模式 |
| `H` | 收起 / 展开顶栏 |
| `Esc` | 关闭弹窗、控制台或录屏模式；倒计时期间取消倒计时 |
| `Ctrl / Cmd + Enter` | 在剧本编辑区应用剧本 |

## 录屏建议

1. 调整浏览器窗口为竖屏比例，或直接使用录屏软件裁切手机区域。
2. 点击右上角“录屏模式”，在播放器右侧把“倒计时”调成 6 秒左右，按 `R` 从头播放。先按下录屏，再等倒计时归零开演；中途想重来就点播放键或按 `Esc` 取消。
3. 将鼠标移开，2.8 秒后底部控制条自动隐藏。
4. 录制完成后按 `Esc` 退出录屏模式。

> 提示：导入弹窗只替换 `SCRIPT`，不会清空 `INITIAL`。若想让导入内容从空白开场，把 `INITIAL` 设置为 `[]` 即可。
